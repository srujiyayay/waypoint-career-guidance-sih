# 🧭 Waypoint – AI-Enhanced Career Guidance

**One profile. Many possible paths. One that actually fits.**

Waypoint is a career-guidance prototype designed to help students explore career options based on their education, existing skills, interests, and goals. It aims to make career exploration more personal by showing suitable career matches, identifying skills to build, and providing a step-by-step roadmap.

Developed by **Team Unethical Hackers** for **Smart India Hackathon 2026**.

## The Problem

Students often have to make career decisions with limited guidance. Generic recommendations may not consider their individual strengths, interests, or the skills needed to enter a particular field. It can also be difficult to know what to learn next.

## Our Solution

Waypoint brings a student's profile, skills, and interests together to generate career suggestions and a learning roadmap. It also distinguishes between skills a student already has and fields they are interested in exploring.

## Features

- **Student profile:** Enter a name, age, educational qualification, and an optional career goal.
- **Skill assessment:** Select existing skills and answer follow-up questions about proficiency, experience, and tools used.
- **Interest profiling:** Choose areas of interest separately from current skills.
- **Career matching:** View a best-fit career suggestion and other career options worth exploring.
- **Skill-gap analysis:** See skills that may need further development for the suggested career.
- **Adaptive roadmap:** View suggested steps and mark roadmap items as completed to update progress.
- **Responsive layout:** Includes layouts for different screen sizes and reduced-motion preferences.

## How It Works

1. Enter your basic profile details and education level.
2. Select skills you already have.
3. Answer the follow-up questions shown for your selected skills.
4. Select areas you are interested in exploring and answer the related questions.
5. Choose **Generate my pathway** to view career matches.
6. Review your recommended role, other matches, and suggested skill gaps.
7. Work through the roadmap and mark completed steps to track progress.

## Technologies Used

### Current prototype
- **HTML5** – page structure
- **CSS3** – layout, styling, responsive design, and animations
- **JavaScript** – skill and interest questions, career scoring, recommendations, and roadmap interactions
- **Google Fonts** – typography

### Proposed production direction
The page also outlines a possible future architecture using React.js, Python/FastAPI, PostgreSQL, an LLM-based recommendation component, and career/skill data sources such as O*NET and ESCO. These are proposed technologies; they are **not** part of the current standalone browser prototype.

No build tools or backend setup are required for the current prototype.

1. Clone the repository:

   ```bash

   ```

2. Open the project folder:

   ```bash
   cd Waypoint
   ```

3. Open `index.html` in a web browser.

You can also use the **Live Server** extension in Visual Studio Code if you prefer to run it through a local development server.

## Future Improvements

- Connect the prototype to a backend and database for user accounts and saved progress.
- Integrate an LLM or a more advanced recommendation model.
- Use maintained career and skill datasets to improve recommendations.
- Add learning-resource links for each roadmap step.
- Allow students to save, revisit, and update their career plans.
- Evaluate recommendation quality with student feedback and testing.

## Note

The current version is a front-end prototype. Its career recommendations are generated by browser-side JavaScript logic; it does not currently call a live AI service or store user profiles in a backend.
